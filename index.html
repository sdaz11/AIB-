05 / Architecture

SEPARATE
INTELLIGENCE
FROM
AUTHORITY.

The prototype deliberately splits probabilistic analysis from deterministic control.

Interface

Streamlit Investigator Interface

Case selection, investigation results, HITL review, benchmark, governance and audit evidence.

Application

Python Application + Agent Orchestrator

Coordinates evidence, live model calls, structured outputs and deterministic routing logic.

Intelligence

4 Live Specialist LLM Agents via OpenRouter

Transaction Intelligence · Customer Behaviour · Policy & Risk · Recommendation.

LLM RECOMMENDATION ≠ AUTHORITATIVE GOVERNANCE DECISION

Model output is advisory. Policy thresholds decide the permitted route.

Governance

Deterministic Governance Engine

Authoritative LOW / MEDIUM / HIGH / fail-safe decision rules.

Workflow

n8n Orchestration

Conditional routing and process visibility. The n8n agent-labelled nodes are logical workflow representations, not the live LLM runtime.

Authority

Human-in-the-Loop

Required for customer verification, high-risk review and escalation.

Trace

Persistent Append-only JSONL Audit

Records model runs, workflow metadata, security tests and human decisions.

06 / Governance Routing

POLICY
OWNS THE ROUTE.

LOW / [A]

Low-risk activity can proceed through the governed path without unnecessary investigator friction.

PROCEED
MEDIUM / [H]

Human Verification Route

VERIFY CUSTOMER

Human Review + Escalation

High-risk evidence is held for human review and explicit escalation.

HOLD AND REVIEW
UNKNOWN / FAIL-SAFE
